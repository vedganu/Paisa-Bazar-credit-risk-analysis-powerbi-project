# Credit Risk Analysis Dashboard – Power BI

An interactive Credit Risk Analysis dashboard developed using Power BI to analyze customer credit profiles, loan-related risk indicators, debt distribution, and financial health.

## Project Overview

This project focuses on analyzing credit risk data for a fictional NBFC (Non-Banking Financial Company), Paisabazaar, to help understand customer risk distribution and support data-driven decision-making.

## Tools Used
- Power BI
- Power Query
- Data Cleaning
- Data Transformation
- Data Visualization
- DAX

## Key Insights
- Customer credit risk distribution
- Good, Standard, and Poor credit categories
- Customer debt analysis
- Credit score and financial indicators
- Age-group analysis
- Risk patterns across customer segments

## Dashboard Features
- Interactive filters and slicers
- KPI cards
- Credit risk distribution visualizations
- Customer segmentation
- Financial analysis

## Project Purpose
To demonstrate practical skills in data analytics, dashboard development, data visualization, data cleaning, and business insight generation.

## Disclaimer
This project uses fictional/synthetic data for educational and portfolio purposes.
